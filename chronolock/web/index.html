    About

    ChronoLock names a morning window so people can read what you share. The window is 08:30–10:30 local. It does not change the words. It does not post.

    Simple view is the default. Open Advanced for import, export, verify, and time zones.

    Public name of the Chronolect Layer (formerly prototyped as StaticClock). The staticclock command still works: it prints one deprecation line, then runs ChronoLock. StaticClock itself is not deleted.

    Advisory hygiene, not a scheduler. Five fields: place, time, date, language, dialect.
